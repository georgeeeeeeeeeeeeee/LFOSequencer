LFO Sequencer @VERSION@ for Windows
===================================

Up to 4 slow LFOs that play MIDI notes and send MIDI CC to your synths.
Free and open source (GNU AGPLv3).

Needs: 64-bit Windows 10 or 11 and a 64-bit VST3 host such as Ableton Live.
No installer and no extra runtimes are needed.


1. INSTALL
----------
1. Right-click the zip and choose "Extract All...".
2. Copy the whole "LFO Sequencer.vst3" folder into:

       C:\Program Files\Common Files\VST3

   Windows asks for administrator permission; click Continue.


2. USE IT IN ABLETON LIVE
-------------------------
1. Options > Settings (Preferences in older versions) > Plug-Ins: turn on
   "Use VST3 Plug-In System Folders", then click Rescan.
2. Load LFO Sequencer on a MIDI track.
3. On a second MIDI track with your instrument, set "MIDI From" to the
   LFO Sequencer track, and choose "LFO Sequencer" in the box below it.
4. Arm or monitor the instrument track. Double-click any value box to type
   a new value.

Not showing up? Check that you copied the whole "LFO Sequencer.vst3" folder
(not just the file inside it) and that your host is 64-bit.
